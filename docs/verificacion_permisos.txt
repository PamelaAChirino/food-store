NOTA: esta base de verificación acumula objetos de TPs anteriores (TP4 FNBC:
control_lote_almacen_legacy, etc.) porque se usó el mismo entorno de prueba
para no rearmar el esquema completo de Food Store en cada corrida. Los
objetos relevantes para esta Unidad 5 son: cliente, producto, categoria,
pedido, pedido_producto, credencial_acceso, intento_login, log_auditoria y
usuario_anon.

Dato a destacar: credencial_acceso, intento_login, log_auditoria y
usuario_anon se crearon DESPUÉS de correr roles.sql, y ya aparecen en la
tabla con los privilegios correctos para rol_app_lectura / rol_app_escritura
/ rol_reportes -- eso confirma que el ALTER DEFAULT PRIVILEGES del punto 7
de roles.sql funciona: las tablas futuras heredan la política sin necesidad
de un GRANT manual adicional.
